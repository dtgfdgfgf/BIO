# 迭代紀律 / Iteration discipline

從專案中實際失敗訂出的「紀律零＋九條」通用版。每條會寫：起因（去識別化）、規則、執行方式（機械檢查或人簽核）。

A generalized version of the ten rules ("rule zero plus nine") that came out of real failures in the project. Each rule will state its origin (anonymized), the rule itself, and how it is enforced (automated check or human sign-off).
