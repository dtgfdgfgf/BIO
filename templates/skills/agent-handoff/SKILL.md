# 雙代理接手與交接

> 規則正本＝`docs/agent_collaboration_protocol.md`（兩個代理共讀）。本 skill 是那份協定的精簡入口，正本有出入時以正本為準。

## 1. 每樣東西只有一個正本

| 事物 | 正本（只在這裡改） | 另一個代理怎麼看到 |
|---|---|---|
| 專案指令 | `AGENTS.md` | Claude Code：`CLAUDE.md` 第一行 `@AGENTS.md` 匯入 |
| 專案 skills | `.claude/skills/<name>/` | Codex：`.agents/skills/<name>/`＝鏡射，由同步腳本產生，不手改 |
| 進度與拍板 | `docs/README.md` → `docs/current/` 現況表 | 兩邊相同 |
| 交接摘要 | `docs/current/agent_handoff.md` | 待核對的摘要；不是規格、不是寫入鎖 |

- 聊天記憶不共享。一邊匯入另一邊的對話紀錄時，只當線索，不當證據。
- 「已完成」「測試通過」如果沒有可以核對的證據（commit、檔案、輸出、log），一律標「未驗證」。

## 2. 接手（每次 session 開工）

1. 讀專案指令 → 入口路由 → 協作協定 → 交接卡。
2. 跑唯讀探測腳本，輸出就是接手證據：branch、完整 HEAD、status、diff 統計、skills 鏡射檢查。
3. 拿探測結果對交接卡：HEAD、未提交檔案清單、變更歸屬三項一致嗎？
4. **給每個未提交的檔案歸屬**：本次／前一個代理（卡上有記）／使用者／來源不明。來源不明且跟本次任務無關就保留並繞開；跟本次任務直接衝突就停止寫入，請使用者決定。不因為檔案已經存在，就假設是自己或另一個代理寫的。
5. 一句話回報：接手目標、卡和實況的差異、本次修改範圍。只做分析的 session 不改檔、不動卡。

交接卡是 `IDLE` 或不存在時，直接依 repo 證據重建背景，不要求使用者重貼對話。

## 3. 寫入權

- **同一個 working tree 同時只有一個寫入者**，由使用者指定。另一個代理只做不產生輸出的唯讀動作；建置、格式化、測試都會寫產物，不算唯讀。
- 無法確定另一個代理是否還在寫，先問使用者，不擅自停掉別人的 session。
- 真要並行：提議不同的 worktree 或 branch 與分工範圍，取得授權才建立。worktree 不會隔離執行檔目錄、輸出目錄和硬體資源（序列埠、相機、PLC），也不帶被 git 忽略的建置依賴，每一項都要明確分開。
- 發現寫入範圍重疊：停止自己的衝突寫入，保留雙方變更，請使用者決定整合順序。
- **非寫入者的最高價值是質疑者，不是第二個寫手。** 它獨立回答紀律零的開工前四問，跟寫入者的答案對照，不一致就交給使用者裁定；它不改碼、不產包、不提修改案。（我同意了這條，但一直沒有正式啟用。）

## 4. 交接卡

- **什麼時候寫**：使用者明說「交接給 X」「更新交接卡」時才寫。問「目前進度」只回覆，不寫檔。寫卡只授權寫卡，不授權改程式、commit 或碰硬體。
- **怎麼寫**：照下面的章節全部重填、不留舊內容；「Repository 基準」直接貼探測腳本輸出。
- **不寫**：secrets、整段對話、和任務無關的私人資料、另一份規格（規格寫進現況表，卡只指過去）。

```markdown
# 交接卡

狀態：READY ／ IN_PROGRESS ／ BLOCKED ／ IDLE
（READY＝可接手，不等於產品驗收通過）
寫卡者：<Claude Code／Codex>，<日期時間>
接手者：<…>

## 目標
<一句話：這個任務要達成什麼>

## Repository 基準
<貼探測腳本輸出：branch、完整 HEAD、status 清單>

## 變更歸屬
| 檔案 | 誰改的 | 狀態（已驗證／未驗證） |

## 已完成（附證據）
- <事項> — 證據：<commit／檔案／輸出路徑>

## 未完成與下一步
- <事項>

## 待使用者決定
- <問題＋選項>

## 不要碰
- <檔案或資源＋原因>
```

## 5. Skills 與指令檔防漂移

- **改 skill**：只改 `.claude/skills/<name>/`，跑同步腳本鏡射到 `.agents/skills/`，再不帶參數跑一次確認全部相同。
- 同步只做正本 → 鏡射：鏡射側多出來的 skill 不刪，回報「缺正本」（代表有人直接在鏡射側建了 skill，搬到正本再同步）；鏡射檔有未提交修改時拒絕覆蓋。
- **新增 skill**：資料夾名＝frontmatter 的 `name`（小寫英數與連字號，64 字以內）；`description` 1024 字以內，觸發詞放前面。
- **改專案指令**：只改 `AGENTS.md`；`CLAUDE.md` 只放匯入行和 Claude 專用補充。`AGENTS.md` 裡不能用 `@` 匯入，Codex 沒有這個語法。

## 不做什麼

不自動同步聊天；不建 branch、不 stage、commit、stash、reset、clean。遇到寫入重疊、來源不明而且衝突的未提交修改、證據互相矛盾、或缺授權：保留現況，請使用者決定。
