# 檢測線三階段 SOP（研究 → 定版 → 接入）

> 迭代紀律正本＝`docs/iteration_discipline.md`；覆核包格式＝`review-pack` skill；建置指令＝`<build-skill>`；機台程式地圖＝`<map-skill>`。本 skill 只寫流程骨架，不重複它們的內容。

## 開發模式：生產語言優先

- **凡是碰像素的運算，直接寫在生產語言裡**（機台用什麼語言、什麼影像函式庫，就寫什麼）。只有一份實作，常數天生就屬於生產環境。
- 研究腳本降級成「讀掃描輸出的分析層」：畫分佈、做統計，不碰影像解碼。
- **所有進入定版文件的數字，都要出自生產實作的掃描輸出。**
- 為什麼：我們先試過「研究語言寫好再移植」，踩到兩種解碼函式庫讀出來的像素不一樣，常數要重校，還要維護兩套實作的逐張對拍。

## 階段一：研究（只新增檔案，可自由迭代）

新的檢測器＝演算法資料夾下的**獨立新檔**＋**獨立驗證程式（harness）**。harness 用連結的方式編譯機台**同一份**原始碼。只新增檔案、不碰既有檔，就不需要「改既有檔」的授權；把新檔加進機台專案屬於接入階段。

### 起手 checklist

- [ ] **方法選擇書先於第一個原型**（紀律八）：在現況卡開「方法族」節，列至少三族由簡到繁；**最簡那族實跑**，失敗處出方法包；使用者在基準失敗圖上簽「修同族／換族」後，才開始寫檢測器。
- [ ] 檢測器新檔：無狀態（可跨執行緒共用）；門檻從參數傳入並附內建預設；綁取像條件的常數寫死，並在檔頭註明取像條件。
- [ ] harness 新專案：連結機台同一份原始碼；凡連結主流程的 harness，要帶齊主流程引用的所有檢測器檔。

### 迭代迴路

```text
改檢測器 → 建置 harness → 全量掃描出 CSV
→（可選）研究腳本讀 CSV 出分佈 → LLM 逐條看圖初判 → 產覆核包 → 使用者覆核
→ 讀覆核結果 → 診斷表（不改碼）→ 改動計畫（類型＋預期翻轉＋保護反例）→ 回到改檢測器
封存集：改動凍結後才跑、只回總數。每輪報該線 CPU 核心秒。
```

### 研究期鐵律

| 鐵律 | 內容 |
|---|---|
| 原圖 | 演算法一律跑原圖，不縮圖。速度不能靠平行化解決，效能以 CPU 核心秒計帳 |
| 說明義務 | 每輪完整說明管線、門檻、NG／OK 區分方法，不能只丟覆核包 |
| 門檻不盲調 | 判定標準等使用者拍板；規格或標註樣本到位前不調 |
| 迭代紀律 | 每次改動附「紀律檢核」區塊 |

### 參數挖口的同步鏈

把檢測器的寫死常數改成可調參數時，一次走完，缺一步就會產生真相漂移：

- [ ] 檢測器挖口（動既有檔，先取得同意）。「不調」的語意要定清楚：判定層參數傳 0＝用內建凍結值；影像處理參數不用 0 當哨兵，直接跳過賦值。
- [ ] 參數描述檔加一行；預設值必須等於程式裡的初始值，工具啟動時逐顆核對，不相等就報錯。參數名稱寫白話（這顆鈕在問什麼），術語和程式名放說明欄。
- [ ] 掃描驗證：新參數接線有效（改了輸出會變）；用預設值跑全量，逐位零迴歸。
- [ ] 重新產生調參地圖（如果有）。

## 階段二：定版

- [ ] **常數凍結**：寫死在檢測器檔裡，並標明取像條件。
- [ ] **紀律四、五齊備**：門檻附全體分佈與 ±20％ 靈敏度；至少一批不同日期取像的重拍結果；至少一組事前抽樣、沒讀過逐張細節的封存集結果；改法期間人工標籤、樣品、分母都沒變。
- [ ] **紀律八記分板核對**：列數不少於換族次數，每列都有下場；定版那一族的下場寫「定版」。
- [ ] **紀律七效能在預算內**，或使用者明示例外並記錄理由。超標時不得宣稱可上線。
- [ ] **研究正本文件**：背景與拍板 → 資料與錨點 → 演算法 → 全量掃描結果 → 逐版迭代 → 已知限制 → 檔案清單；數字都出自生產實作的掃描輸出。
- [ ] **定版覆核包留存**；歷史包不刪。
- [ ] **同步更新現況卡＋入口路由。兩者都改，才算定版。**
- [ ] 歷史檔不改寫；工具不搬移、不刪除（路徑寫死）。

## 階段三：接入（動既有檔，先列改動清單取得同意）

| 面 | 要做的事 |
|---|---|
| 掛點 | 主流程加新的量測呼叫；和其他線的分派關係（例如前一線判 NG 就跳過）照使用者拍板 |
| 結果契約 | 新的 NG 項目、量測值走既有的結果機制 |
| 配方 | 新增一個區段；**`enable` 預設 false**（只量測不判定，等門檻拍板）；門檻小於等於 0 時退回內建凍結值；**舊配方沒有這個區段＝不量測＝完全相容**；數值欄用寬鬆型別讀（整數欄填了 `6.0` 不能讓整份配方讀取失敗） |
| 報表 | 加欄位時注意既有欄位順移；欄名經使用者拍板 |
| 防呆 | 輸入尺寸不符＝標記未量測；量測函式內層一定接住例外、絕不往外丟；影像資源在例外路徑也要釋放 |

### 零迴歸驗證（全部實跑）

- [ ] 機台建置 0 錯誤。
- [ ] **受影響的各線全量掃描，與基線逐位 diff＝0。**
- [ ] 配方、報表、主流程的 smoke 測試全部 PASS。
- [ ] 機台離線啟動並截圖：完整介面、沒有錯誤對話框、沒有啟動錯誤 log。
- [ ] 對抗覆核：另一個角度找碴，發現就修正並重驗。

### 收尾

- [ ] 接入記錄文件：接入設計 → 取像條件與對拍契約 → 驗證表 → 改動清單 → 限制與後續。
- [ ] 現況卡＋入口路由同步，寫明接入狀態與 `enable` 預設值。
- [ ] 講機台狀態時，「接入」和「部署」分開講。
- [ ] commit 等使用者下令；只 stage 本次動到的檔。
